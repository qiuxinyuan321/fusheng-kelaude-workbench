# 多账号轮询（可选插件）

默认关闭，在插件管理中启用并授权后生效。账号选择、会话绑定、迁移规则与界面全部位于本插件目录。宿主只负责通用后端桥、执行锁、生命周期和运行配置传递。

## 使用

1. 启用「多账号轮询」，保留默认策略即可继续使用工作台原有的官方账号。
2. 在「添加一个账号」里起个名字并点「添加账号」，再点新卡片上的「登录说明」。以运行工作台的同一系统用户，在同一服务器执行给出的 `claude auth login --claudeai` 命令。登录期间请停止工作台任务；命令不会由网页自动执行。
3. 登录完成后点击「登录完成，刷新状态」。卡片显示套餐、状态，以及 5 小时已用和本周剩余的进度条与重置倒计时。账号邮箱仅显示脱敏形式，密码、OAuth Token 和授权码不进入插件存储。
4. 在「每轮开始时怎么选账号」里点选「保持当前账号」「轮流使用」或「余量优先」，「提前换号」可选已用 90%、95%、98% 或仅用尽后，点了立即生效。「会话使用的账号」列表里可以把会话固定到一个账号，改回「自动」后继续跟随选择方式。固定的账号额度用尽、登录失效或被停用时，下一轮自动交给选择方式挑别的账号，该会话随之改为「自动」。
5. 「额度用尽时自动换号继续」默认开启：一轮任务因官方额度用尽中断后，工作台换到下一个有余量的账号，在同一个官方会话里发一条说明让 Claude 接着做原任务。每项任务每个账号最多试一次；所有账号都用尽时停下并在面板、侧边栏和账号选择器里提示。用户先停止、发送新消息或归档时不再续接；关掉这个开关后只会在下一轮换号，不会自动继续。
6. 侧边栏的「账号空间」显示已登录账号数和账号总数，点击打开本插件面板。输入框旁的账号选择器选「自动选择」或某个账号：已有会话立即改绑（本轮运行中锁定）；新对话在发送第一条消息时一并生效。未固定的会话显示「自动 · 上次使用的账号」。

额外配置在 `<DATA_DIR>/server-plugin-data/account-pool/profiles/<id>/config`，由官方 `CLAUDE_CONFIG_DIR` 隔离。默认账号沿用官方默认配置，插件不复制或改写凭据。所有账号都不存在、未确认登录、停用或无可用额度时明确拒绝启动，不悄悄使用另一个未授权配置。

额度读取复用工作台通用的官方 `/usage` 能力。未知额度不会显示为零；轮询与保持策略可使用尚无额度观测但已登录的账号，余量优先把未知额度排在已知额度之后。官方限额拒绝会在冷却窗口内阻止再次选择。插件只在新一轮开始前选择账号；额度用尽的续接发送的是说明和原任务文字，不重放工具调用。进程失败、服务中断等其他中断交给独立的任务续接插件。

## 会话连续性与停用

切换账号保留工作区和官方会话 UUID，只迁移该会话的 `projects/<project>/<session>.jsonl`、该会话的子代理记录与 `file-history/<session>`。不复制配置、凭据、缓存或其他会话；拒绝软链接、硬链接和超过 128 MiB / 10,000 条目的记录。官方 CLI 存储布局变化时需要回归测试。

已使用独立账号的会话由宿主记录插件所有权。停用插件会停止新动作；这类会话不能直接落回默认账号，须重新启用插件继续，或先绑定默认账号并成功运行一轮完成记录迁移。停用不会删除账号配置或历史记录。清理整个插件数据目录前应先备份，并确认已不需要其中的官方登录与会话数据。

## 模块契约

`server.mjs` 导出 `createAccountPool(options)`。`dataDir` 是插件私有目录，`workspaceRoot`、`binary`、`legacyConfigDir`、`env` 由宿主提供。`withExclusive(fn)` 必须使用与任务、终端相同的执行互斥，`isActive()` 必须反映当前启用和授权状态；`getSession(id)` 用于验证会话绑定。`startTurn(session, text, request)` 是宿主开始一轮的入口，用于额度用尽后的续接；未提供时不续接。`onNotes()` 在换号提示变化时调用，宿主据此通知已打开的页面。测试可注入 `authProvider`、`usageFactory`、`exec` 与 `now`。

- `call(method, params)`：`list`、`create`、`update`、`settings`、`bind`、`refresh`、`loginCommand`。`create`、`update`、`settings` 通过共享锁；`bind` 和 `refresh` 只排在本插件队列里，其他会话运行时也能切换账号、刷新登录与额度（`bind` 拒绝正在运行的会话）；返回值只包含插件元数据与脱敏状态。`list` 另含 `notes`：按会话记录的换号提示（`continuing`、`continued`、`released`、`failed`）。`settings` 接受 `strategy`、`switchAt`、`autoContinue`。
- `beforeRun({session,cwd,request,kind})`：宿主已持执行锁时调用，返回 `{accountId,configDir}`。不得在此嵌套获取宿主锁。`request.choice` 是新对话第一条消息带来的选择：`auto` 解除固定，账号 ID 固定到该账号（须存在且已启用）。固定账号不能运行时按选择方式另选并解除固定。`request.source === 'account-pool'` 的续接轮带 `handoff`，排除已用尽的账号。
- `onEvent({session,event})`：接收通用 `quota` 与 `rate_limit` 事件，更新本轮所用账号的额度观测。
- `onExit({session,run,result})`：`result.limitReached` 表示官方 CLI 因额度用尽结束了本轮（宿主运行器在限额拒绝后的错误结果上设置）。插件等 `run.done`（宿主释放会话）后在下一个账号上续接；`stopped`、`shutdown`、`preflightFailed` 或其他退出不续接。遇到 409（宿主短暂持锁或并发已满）时最多重试 5 次，每次间隔 3 秒。
- `close()`：停止监控，进行中的续接不再启动。
- `sessionState(id)`、`ownsSession(session)`：读取插件记录的当前账号及会话记录来源。
- `executionStatus()`：空闲时借助共享锁刷新登录状态（缓存 60 秒）；任务或终端忙时仅使用缓存，返回可运行性和简短说明，不暴露邮箱。

账号元数据使用独立文件与临时文件原子替换；坏配置会明确报错，不自动覆盖。生产部署应限制数据目录为工作台系统用户可读写，并按服务器正常数据备份策略保存。

## 版本记录

- 1.3.0：新增按账号隔离的后台 CLI 探针协调锁（对话轮次与原生 Claude 终端占用账号前排空在途探针，运行期间暂缓该账号后台 `auth` / `/usage` / 模型探测，避免并发刷新 OAuth refresh token）；已登录账号自动通过宿主的零对话 CLI `initialize` 探针同步独立配置目录的模型目录（如 Fable 5.2、Haiku 5.5）；账号卡片与输入框选择器新增模型专属周额度（`weekly_scoped`，如 `Fable 周剩余`）展示。需要工作台 1.7.0 及以上。
- 1.2.0：额度用尽后自动换到下一个账号，在同一会话里接着做原任务（可在面板关闭）；固定的账号用尽、登出或停用时交给选择方式，不再卡住会话；面板、侧边栏和账号选择器显示「换号中」「已换到…」「未能换号」。刷新登录与额度不再等其他会话的任务结束。需要工作台 1.6.2 及以上（运行器上报 `limitReached`）。
- 1.1.0：侧边栏「账号空间」入口和输入框账号选择器；切换已有会话的账号不再需要等其他会话结束；新对话可以在发送前选好账号。面板重新排版：账号卡片带额度进度条和重置倒计时，选择方式和会话绑定点选即生效。需要工作台 1.6.0 及以上。
- 1.0.1：按模型系列匹配每周额度，Fable 和指定版本（如 `claude-opus-4-6`）的轮次也计入各自系列的周额度；`seven_day_fable` 等限额类型显示为「Fable 本周额度」。需要工作台 1.3.0 及以上。
- 1.0.0：首个版本。
